# Dossier

An Obsidian reading-view renderer: refined typography, tables, callouts, code and
task-lists; mermaid re-rendered as framed diagram cards; a rich-viz dashboard block;
a document masthead, table-of-contents and floating section-nav; and a theme switcher.
Applies vault-wide in reading view; never modifies your notes.

## Install

**Via BRAT (recommended, auto-updating):**

1. Install the [BRAT](https://github.com/TfTHacker/obsidian42-brat) community plugin.
2. BRAT → **Add beta plugin** → paste this repository's URL.
3. Enable **Dossier** in Community plugins.

**Manual:**

Copy `main.js`, `manifest.json`, and `styles.css` from the latest
[release](https://github.com/coeverywhere/dossier/releases) into
`.obsidian/plugins/dossier/` in your vault, then enable **Dossier** in
Community plugins.

Requires Obsidian 1.13.7 or newer. Desktop only.
